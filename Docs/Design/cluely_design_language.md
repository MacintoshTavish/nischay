# Cluely Design Language: Premium Stealth Identity

This document captures the distilled design system of **Cluely.com**, which serves as the visual foundation for the Nischay web portal.

## 🎨 Color Palette
- **Base Environment**: `#090910` (Ultra-dark navy/black).
- **Surface Layer**: `rgba(255, 255, 255, 0.05)` (Frosted glass).
- **Core Accent**: `#2B6BF3` (Electric Blue).
- **Typography High-Contrast**: `#FFFFFF` (Pure White).
- **Typography Medium-Contrast**: `#A1A1AA` (Zinc-400).
- **Border/Ring**: `rgba(255, 255, 255, 0.1)` (Ghost border).

## 🖋 Typography
- **Primary Font**: [Manrope](https://fonts.google.com/specimen/Manrope) (Sans-serif).
- **Heading 1**: 72px - 84px | Extra Bold (800) | -0.04em tracking.
- **Heading 2**: 48px - 60px | Bold (700) | -0.03em tracking.
- **Body**: 16px - 18px | Medium (500) | 1.6 line-height.

## ✨ Visual Motifs
- **Glassmorphism**: 
  - `backdrop-filter: blur(16px)`
  - `background: rgba(255, 255, 255, 0.03)`
  - `border: 1px solid rgba(255, 255, 255, 0.08)`
- **Dynamic Lighting**: Radial and vertical "light spills" in Indigo/Violet behind cards to create depth.
- **Noise Texture**: A global 2-3% opacity grain overlay for a tactical/premium feel.

## 🛠 Component Specs
- **Pill Buttons**: 48px height | 24px padding-x | 12px border-radius.
- **Feature Cards**: 32px border-radius | inset shadow | heavy backdrop blur.
- **Navigation**: High-positioned floating pill | `backdrop-blur-xl`.
